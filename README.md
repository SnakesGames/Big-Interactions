# Gorilla Simulator X website

Official website for **Gorilla Simulator X**, a multiplayer pet-collecting VR game for Meta Quest by Big Interactions.

- `index.html` - home page, game info, Halloween event, screenshots and trailer
- `terms.html` - Terms of Service
- `privacy.html` - Privacy Policy
- `assets/` - logo, screenshots and trailer

## Hosting on GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings > Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, and save.
3. After a minute the site is live at `https://<your-username>.github.io/gorilla-simulator-x-website/`.

Links for the Meta Horizon Store dashboard:
- Privacy Policy: `https://<your-username>.github.io/gorilla-simulator-x-website/privacy.html`
- Terms of Service: `https://<your-username>.github.io/gorilla-simulator-x-website/terms.html`
